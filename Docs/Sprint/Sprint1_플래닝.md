## 증분 (Increment)
스프린트가 끝나는 10-22에 나오는, 실제로 동작하는 결과물.

- **Sprint 1 프로토타입 빌드**: 플레이어가 맵을 이동하고, 오브젝트를 조사하면 대사가 출력되며, 저주 시스템이 작동하는 것을 한 번에 플레이할 수 있는 빌드
- 빌드에 배경 1장 이상과 주인공 SD가 적용되어 있다
- 함께 나오는 산출물: 프롤로그 게임 플로우 차트, 메인 UI·설정 UI 시안, 아트 리소스(배경, 캐릭터 시트, 스탠딩 일러스트)

## 완료 기준
**프로그래밍**
- 합친 빌드에서 플레이어가 맵을 이동하고, 조사 가능한 오브젝트에 다가가 상호작용하면 대사가 출력된다.
- 스크립트 파일에 적은 대사가 순서대로 출력되고, 입력으로 다음 대사로 넘어간다.
- 저주 시스템이 정상 작동 되는 것을 빌드에서 확인할 수 있다.

**기획**
- 프롤로그 시작부터 끝까지의 게임 플로우 차트가 완성되어 팀에 공유됐다.
- 메인 UI·설정 UI 시안이 완성되어 팀 리뷰를 받았다.

**아트**
- 배경(봉인실/집, 복도), 주인공 SD, 캐릭터 시트, 스탠딩 일러스트(주인공·간호사 그림자·고모)가 완성되어 공용 폴더에 정해진 이름으로 올라갔다.
- 배경 1장 이상과 주인공 SD가 빌드에 임시로라도 들어가 있다.

**공통**
- 스프린트 리뷰 때 팀 전원이 빌드를 한 번 이상 플레이했다.
- 모든 이슈가 Done 또는 다음 스프린트로 이월 처리됐다.
